# 에이블램 명함 스튜디오

텍스트 없는 명함 배경에 이름과 연락처를 넣고, 드래그와 서식 도구로 편집하는 로컬 MVP입니다. API 키 없이 실행됩니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```sh
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:5173/ 을 엽니다. macOS에서는 `start.command`를 실행해도 됩니다.

배포 가능한 정적 파일은 `npm run build`로 `dist/`에 생성됩니다. `npm run preview`로 빌드 결과를 확인할 수 있습니다.

## 사용 순서

1. 미리보기 위 **규격**에서 가로·세로를 mm로 입력하고 **적용**을 누릅니다. 기본값은 90×50 mm이며 10–300 mm 범위에서 0.1 mm 단위로 직접 설정할 수 있습니다. 가로형·세로형·정사각형을 같은 방식으로 만듭니다. 규격 변경은 실행 취소할 수 있고 자동 저장됩니다.
2. 왼쪽 **텍스트**에서 이름·직함·회사·전화·이메일·주소를 입력합니다.
3. 명함 위 글자를 선택해 드래그합니다. 더블클릭하면 해당 입력칸으로 이동합니다. 위 도구에서 글꼴·크기·굵기·정렬·색상·자간을 바꿉니다. 방향키는 조금씩, Shift+방향키는 더 크게 움직입니다.
4. **배경** 탭에서 분위기를 입력하고 **배경 변형 보기**를 누르거나 직접 배경 이미지를 넣습니다. 현재 예시 기능은 페이퍼·미드나이트·세이지 스타일과 곡선 변형을 제공합니다. 파일 용량 10 MB 제한은 없으며, 큰 이미지는 긴 변 2160 px 이내로 조정해 저장합니다. 브라우저가 읽을 수 있는 PNG·JPEG·WebP 파일을 사용합니다.
5. **빠른 배치 정리**에서 현재 명함과 추천 배치를 비교합니다. **단정하게 / 중앙으로 / 이름을 강조** 중 선택하고 **이 시안 적용**을 누릅니다. 문구와 배경은 보존되며 적용 뒤에도 직접 편집할 수 있습니다.
6. **이미지 저장**에서 PNG 또는 JPEG와 기본/고해상도 크기를 선택합니다. 픽셀 크기는 설정한 규격에 따라 바뀝니다. 예를 들어 85×55 mm는 1020×660 또는 2040×1320 px로 저장됩니다.

편집 내용은 이 브라우저에 자동 저장됩니다. 실행 취소/다시 실행도 제공됩니다. 설정한 규격 비율의 RGB 이미지입니다. 규격 변경 시 텍스트의 위치와 박스 너비는 비례해서 옮기고, 지정한 글자 크기는 유지합니다. 배경 이미지는 중앙을 기준으로 비율을 유지해 채우므로 가장자리가 잘릴 수 있습니다.

## AI 연결 구조

현재 기본 실행은 mock입니다. 실제 GPT/OpenAI 호출은 하지 않습니다.

- `src/ai/mock.js`: 키 없이 배경 생성과 타이포그래피 정리를 시뮬레이션합니다.
- `src/ai/remote.js`: 나중에 서버를 연결할 HTTP 어댑터입니다.
- `src/ai/index.js`: provider 선택을 담당합니다.
- `src/editor/model.js`: AI가 반환한 속성 중 위치와 서식만 적용합니다. 문구·ID·배경은 클라이언트 원본을 보존합니다.
- `src/editor/render.js`: 미리보기와 PNG/JPEG 출력에 공통으로 쓰는 Canvas 렌더러입니다.

로그인된 데스크탑앱의 로컬 Work·Codex에서 실행하는 **에이블램 명함 스튜디오** 플러그인 패키지를 별도로 제작했습니다. 설치·호출용 플러그인, 편집기를 여는 실행 스킬, WebMCP 상태 읽기·배치 제안·배경 비교 기능을 포함합니다. `src/desktop/useDesktopBridge.js`가 사이트 도구와 로컬 전달을 처리합니다. 플러그인의 로컬 서버가 편집기를 열 때 데스크탑 모드가 활성화되며, 일반 Vite 실행에서는 기존 예시 기능을 사용합니다. 이미지 제작은 호스트의 내장 이미지 도구로 요청하고 타이포그래피는 편집 가능한 레이어 속성으로 전달합니다. 전체 설치·연동 흐름은 아직 검증하지 않았습니다.

추후 편의성 개선 범위는 고객별 저장·복제·다시 열기, 정렬 가이드, AI 수정 범위 선택, 납품 편의성입니다. 첫 실행 자동 시안 생성과 시안 3개 동시 비교는 사용자 요청에 따라 범위에서 제외했습니다.

기존 HTTP 어댑터는 선택적인 확장 경로로 남아 있습니다. 원격 서버는 포함하지 않았습니다. 해당 경로의 요청·응답 계약은 [API-CONTRACT.md](API-CONTRACT.md)를 참고하세요.

## 포함된 글꼴

Noto Sans KR와 Noto Serif KR를 로컬에 포함했습니다. 인터넷 연결 없이도 같은 글꼴로 편집·출력할 수 있습니다. `public/fonts/`의 SIL Open Font License 파일을 함께 배포합니다.

## MVP 범위

앞면 한 장, 자유 규격, 텍스트 편집, 배경 업로드/변형 예시, 빠른 배치 정리 예시, 자동 저장, PNG/JPEG 출력입니다. 뒷면, 계정, 서버 저장, CMYK 인쇄용 PDF 및 재단선은 추후 확장할 수 있습니다.

초기 MVP 화면은 [preview.png](preview.png), 당시 확인 내용은 [QA.md](QA.md)에 정리했습니다. 이후 이름, 안내 문구, 업로드 용량 제한과 자유 규격을 변경했습니다. 최신 소스로 배포 파일을 생성했으며 이번 변경에 대해 별도 테스트는 수행하지 않았습니다. 배경 생성 프롬프트는 [ASSETS.md](ASSETS.md)에 있습니다.
