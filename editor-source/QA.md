# 화면과 동작 확인 기록

2026-10-05, 로컬 mock 모드로 확인했습니다.

## 화면 비교

기준 시안: `docs/design-reference.png` (built-in image_gen)

최종 실제 화면: `preview.png` (ego-browser 화면 캡처)

두 이미지를 view_image로 함께 열어 직접 비교했습니다. 시안 원래 크기인 **1536×1024**, 노트북 **1440×800**, 모바일 **390×844**에서 확인했습니다. 실제 브라우저에서도 가로 넘침이 없음을 확인했습니다. Playwright는 사용하지 않았습니다.

| 비교 항목 | 기준과 실제 화면 | 반영 |
|---|---|---|
| 화면 배치 | 흰색 입력 패널, 큰 중앙 명함, 위쪽 서식 도구, 아래쪽 배경/AI 동작 | 패널 너비를 324px로 맞춤. 노트북에서는 명함을 줄여 주요 동작이 보이도록 조정 |
| 글꼴과 위계 | 큰 이름, 작은 직함/연락처, 간결한 UI | Noto Sans KR/Serif KR를 로컬 포함. UI 입력 글자를 읽기 편하게 확대 |
| 색상 | 밝은 회색 작업 영역, 흰 패널, 짙은 초록 동작 버튼 | #f1f3f4 / #ffffff / #153f32 사용 |
| 명함 에셋 | 흰 종이와 오른쪽 곡선, 넉넉한 여백 | built-in image_gen으로 만든 텍스트 없는 배경을 실제 앱에 포함 |
| 간격과 테두리 | 절제된 선, 그림자, 입력칸 간격 | 5~6px 컨트롤 반경과 얇은 테두리. 모바일 서식 도구 가로 넘침 수정 |
| 아이콘과 상태 | 다운로드, 정렬, 선택 박스 | lucide 아이콘을 일관된 크기/굵기로 사용. 실행 취소와 선택 상태 연결 |
| 모바일 | 명함이 우선 보이는 구조 | 명함 아래에 입력 패널, AI 비교는 위아래 배치. 서식 도구와 드래그 확인 |

시안의 구성, 색상, 서체 위계와 편집 흐름을 충실하게 구현해 대조했습니다. 요청 범위에서 해결되지 않은 화면/동작 문제는 확인되지 않았습니다.

의도한 차이: 실행 취소/다시 실행, 자간, 삭제, 배경 만들기 바로가기를 추가했습니다. 원본 보기 버튼은 AI 비교창의 현재 명함 보기로 통합했습니다. 자동 저장의 실제 상태를 표시하고 폰트 선택 메뉴는 포함된 글꼴 이름을 사용합니다. 생성된 배경의 곡선 세부 형태는 시안과 조금 다릅니다. 네이비/세이지와 데모 배경 변형은 Canvas 템플릿입니다.

첫 화면 문구를 대조했고 필수 입력 항목, 텍스트/배경 탭, 편집/정리 단계, 이미지 저장 및 AI 정리 동작 문구를 보존했습니다. 추가 안내 문구는 방향키와 데모 동작을 설명하기 위한 것입니다.

## 동작 확인

- 이름/직함 입력, 고딕→명조 전환, 글자 크기 변경, 드래그, 실행 취소/다시 실행.
- 모바일 서식 도구와 드래그, AI 비교창 표시, 가로 넘침 없음.
- 글자 더블클릭 시 해당 입력칸으로 이동, 빈 이름 재입력, 텍스트 추가/삭제.
- 배경 선택, 분위기에 따른 mock 생성, PNG 배경 업로드.
- AI 스타일 변경과 시안 적용, 적용 뒤 문구와 배경 보존.
- 새로고침 후 자동 저장 내용 복구.
- 실제 다운로드한 PNG와 JPEG의 **2160×1200** 크기와 파일 형식 확인.
- 생성한 이미지 배경을 포함한 PNG 다운로드 확인.
- 긴 주소가 작업 영역 안에 그려지는지 렌더링 경계 확인.
- 잘못된 AI 위치/크기 값 보정, 알 수 없는 ID 무시, 문구/배경 변경 무시. 24개 레이어와 모든 mock 정리 방향 확인.
- `npm run build` 성공.

실제 OpenAI API와 원격 서버는 이번 MVP에서 호출하거나 확인하지 않았습니다. `remote.js`는 후속 서버 연결용 어댑터입니다.
